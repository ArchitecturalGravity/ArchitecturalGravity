# Contributing to Architectural Gravity

Thank you for contributing. Please read `LICENSING.md`, `TRADEMARKS.md`, and
`THIRD_PARTY_NOTICES.md` before submitting material.

## Inbound contribution terms

Contribute only material that you created or are authorized to submit under the
applicable outgoing license identified in `LICENSING.md`. Unless separately
agreed in writing, submissions to Apache-2.0 files are offered under
Apache-2.0, and submissions to CC BY 4.0 files under CC BY 4.0, as applicable.
Do not submit third-party text, code, screenshots, datasets, or model outputs
whose terms prevent redistribution on that basis.

Contributors do not assign their copyrights merely by submitting a change.
Appropriate notices should identify copyright holders and preserve inherited
credits. For any material requiring a different license, disclose that fact
clearly before submitting it.

## Source notices

For project-owned source code, add an SPDX marker and the correct holder where
practicable:

```python
# Copyright (c) 2026 Architectural Gravity LLC
# SPDX-License-Identifier: Apache-2.0
```

For original documentation:

```markdown
<!-- SPDX-License-Identifier: CC-BY-4.0 -->
```

These examples are templates, not permission to remove existing third-party
attribution. Report origins and exact third-party licensing for any reused
material. The project name must not be used to imply the contributor represents
the registered trademark owner or an official release.
