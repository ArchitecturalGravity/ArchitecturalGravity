# Research source anchor audit

Scope: the same 40 curated Markdown sources as the Research validator, including attribution and rights notices, excluding generated AgMark run reports. This inventory includes every heading and subsection at all depths. A generated heading slug is a usable link, not a broken link, but is less stable than an explicit ID. This change did not edit any source Markdown.

The audit found 846 referenced headings: 186 with an explicit ID in the anchor block above the heading, one with a matching detached explicit ID, and 659 using generated slugs. Every heading has a YAML summary. An inline-link scan checked 355 fragments with destinations in these sources.

No unresolved fragments surfaced in that scoped inline-link scan. External links, reference-style links and non-Research destinations were not checked.

## Regenerate the anchor and byte report

From the repository root:

```sh
python3 Research/Agent_References/validate_agent_references.py --report-anchors
```

The TSV gives each source line, heading level, effective key, anchor type, and UTF-8 byte sizes. Source size is the heading's own body before the next heading; empty parent bodies have no meaningful ratio. Compare bytes to prioritize review, not as a pass threshold. Review meaning against the anchored source and refresh fingerprints only after that review.
