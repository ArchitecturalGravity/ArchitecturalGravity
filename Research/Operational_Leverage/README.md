# ArcGrav & Operational Leverage

<a id="ol-operational-leverage"></a>
**Operational leverage** asks how much autonomous work ArcGrav can induce per unit of human specification and intervention effort.

<a id="ol-activity-leverage"></a>
<a id="ol-useful-work-leverage"></a>
**Activity leverage** measures downstream model and tool activity relative to human input; **useful-work leverage** measures validated useful work instead.

<a id="ol-evidence-hierarchy"></a>
## Evidence Hierarchy

Operational-leverage evidence ranges from **agent activity** (such as model and tool use or delegation depth), through **completed work** (produced artifacts and task outcomes), to **validated useful work** (accepted results and demonstrated user or organizational value). Activity measures and specification-normalized activity describe workload and delegation, but do not by themselves establish productivity, quality, or a causal benefit.
