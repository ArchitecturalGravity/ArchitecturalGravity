# Context Triad — Studies

This folder catalogs **individual investigations of the Context Triad**, including pilot observations, controlled experiments, replication attempts, and empirical analyses. Studies can support, qualify, or challenge aspects of the framework. Inclusion does not imply validation or a demonstrated causal mechanism.

## Collection Conventions

Each study should be a standalone, clearly titled paper or report with a descriptive filename and stable heading anchor. Document the exact stimuli and observed outputs when available, model and generation settings, measurement definitions, known limitations, and evidence status. Separate **reported observations**, **hypotheses**, **planned tests**, and **replicated empirical results**.

Study-specific supporting data or code may be added when needed, but no separate folder is required for a single self-contained paper. New studies should be added as sibling files and indexed in the table above.
