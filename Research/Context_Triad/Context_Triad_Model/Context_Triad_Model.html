Model rules

  • Weight sets the height of that letter's peak.
  • Position moves the peak along the context axis from 0 to 1.
  • Shadow intensity is automatic: each weight is normalized against the strongest current weight.
  • A shadow extends horizontally left from the peak, preserving the full height of that weight back to the start of context.
  • Weight influence extends horizontally right from the peak to the end of context, preserving the same full height in the weight's color.
  • Later shadows weaken earlier forward influence. The amount of weakening depends on both shadow opacity and how much of the earlier weight's height the later shadow covers, using a saturating curve so one equal-strength follower weakens rather than erases it.
  • Multiple later shadows compound, so heavily shadowed weights contribute less color to the rightmost context mix.
  • Forward influence stays translucent even at maximum strength, and its alpha is reduced linearly by distance from the right end of context: weights nearer 0 are more transparent, while weights nearer 1 retain more alpha.
  • Where translucent regions overlap, their layers compound.
  • Final Mix averages the alpha-composited surviving color along the full right edge of the graph.

This playground is an illustrative behavioral model, not an empirical fit or a claim about model internals.
