# ArcGrav Design Pattern Catalogue

This directory organizes reusable ArcGrav design patterns by their operational responsibility.

<a id="ag-categories"></a>
## Categories

<a id="ag-contextual-boundary"></a>
### [Contextual Boundary](contextual-boundary.md)
> Defines the task’s scope, objectives, assumptions, success criteria, audience, governing instructions, etc. within clear boundaries.

<a id="ag-resource-discovery"></a>
### [Resource Discovery](resource-discovery.md)
> Identifies and retrieves the files, tools, history, memory, URLs, and external sources needed to complete the task using verified information.

<a id="ag-representation-shaping"></a>
### [Representation Shaping](representation-shaping.md)
> Organizes information into stable schemas, models, templates, and views that support reliable reasoning, reuse, validation, publication, etc.

<a id="ag-state-management"></a>
### [State Management](state-management.md)
> Tracks changing context, working variables, dependencies, checkpoints, cleanup requirements, etc. throughout a multi-step workflow.

<a id="ag-constraint-gating"></a>
### [Constraint Gating](constraint-gating.md)
> Turns policies, safety requirements, business rules, execution conditions, etc. into explicit checks that determine whether an operation may proceed.

<a id="ag-transformation"></a>
### [Transformation](transformation.md)
> Converts source material into structured information or candidate outputs through operations such as parsing, extraction, classification, analysis, synthesis, planning, etc.

<a id="ag-context-integration"></a>
### [Context Integration](context-integration.md)
> Combines retrieved, remembered, derived, tool-produced information, etc. into a coherent context while preserving sources, dependencies, and unresolved conflicts.

<a id="ag-examination"></a>
### [Examination](examination.md)
> Inspects and validates evidence, structures, outputs, etc. against defined criteria to determine their correctness, completeness, quality, and acceptability.

<a id="ag-process-orchestration"></a>
### [Process Orchestration](process-orchestration.md)
> Coordinates task decomposition, routing, sequencing, parallel work, iteration, recovery, termination, etc. across complex workflows.

<a id="ag-resolution"></a>
### [Resolution](resolution.md)
> Resolves supported conflicts, preserves meaningful uncertainty, records provenance & decisions, verifies completeness, and produces a defensible final result.
