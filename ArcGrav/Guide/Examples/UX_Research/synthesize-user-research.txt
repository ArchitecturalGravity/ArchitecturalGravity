[SupportStates]:
- Strongly supported
- Provisionally supported
- Weakly supported
- Unsupported

[EvidenceStandards]:
- Pattern strength depends on independent participant evidence rather than observation count alone
- A theme must cite every supporting evidence reference used to justify it
- Contradictory evidence must remain attached to the theme it challenges
- A single participant can contribute multiple observations without becoming multiple independent participants
- Researcher interpretation must not be restated as direct participant evidence
- Absence of an observed problem is not proof that the problem does not exist

[ThemeAssessments]: []

[Exceptions]: []

[Unresolved]: []

[Synthesis]: []

[AssessThemes]:
=> Assess [CandidateThemes] against [EvidenceStandards]
=> For each candidate in [CandidateThemes] ↳
  - Gather supporting items from [Evidence]
  - Gather contradictory or limiting items from [Evidence]
  - Count independent participants represented on each side
  - Compare the pattern across relevant participant context in [Participants]
  - Record the candidate state from [SupportStates]
  - Preserve every evidence reference used in the assessment
=> Append each result to [ThemeAssessments]

[HandleExceptions]:
=> For each supported or provisionally supported theme:
  - Identify participants whose evidence does not fit the pattern
  - Record the evidence reference and participant context in [Exceptions]
  - Determine whether the exception narrows the theme or challenges it materially
  - Do not remove an exception solely to make the theme more uniform

[Synthesize]:
=> Convert supported patterns into findings that state the observed scope
=> Keep causal explanations in [Unresolved] unless the evidence directly supports them
=> Keep differences by participant experience in [Unresolved] when the sample is too small to attribute the difference reliably
=> Attach supporting evidence references to every finding
=> Attach material exceptions to the finding they limit
=> Append final findings to [Synthesis]

[Validate]:
=> Verify every finding can be traced to [Evidence]
=> Verify no theme uses repeated observations from one participant as independent replication
=> Verify contradictory cases remain visible
=> Verify uncertainty is preserved where the study round cannot resolve cause or population prevalence
=> Verify the synthesis does not generalize beyond the evidence boundary in [ResearchContext]

Task:
1. Run [AssessThemes]
2. Run [HandleExceptions]
3. Run [Synthesize]
4. Run [Validate]
5. Provide [Synthesis]
6. Include [ThemeAssessments]
7. Include [Exceptions]
8. Include [Unresolved]
