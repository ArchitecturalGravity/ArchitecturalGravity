# Examples

ArcGrav examples demonstrate how its structure can be adapted across a wide range of domains, task types, and reasoning needs.

Examples are grouped by category based on their primary task. These categories are illustrative rather than exhaustive: they do not define the boundaries of domains ArcGrav can support.

Likewise, the examples *do not define* a fixed set of supported use cases or styles, structures, or patterns -- they intentionally vary in structure and complexity to showcase how ArcGrav can be utilized.

Within each category, filenames use lowercase kebab-case and follow this pattern:

`<verb>-<object>[-<qualifier>].txt`

Names describe the intended outcome rather than implementation mechanics. Each example begins with a short `# Intent:` comment.
